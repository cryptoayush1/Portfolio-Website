## 📋 About

A fully responsive, dark-themed cybersecurity portfolio website built with vanilla HTML, CSS, and JavaScript — with a Node.js/Express backend powering the contact form.

## ✨ Features

- ⚡ Smooth scroll animations & reveal-on-scroll effects
- 🎨 Premium dark theme with gold accent colours
- 💻 Typing animation in the hero section
- 🛡️ Skills section with animated progress bars
- 📁 Projects section with filter tabs
- 🗓️ Experience & education timeline
- 📰 Real cybersecurity news cards (May 2025)
- 📬 Working contact form via Formspree
- 📄 Resume download button
- 🔗 GitHub & LinkedIn social links
- 📱 Fully responsive (mobile-first)
- 🚀 Rate-limited Express backend

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5, CSS3, Vanilla JavaScript |

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm

### Local Development

```bash
# Clone the repository
git clone https://github.com/cryptoayush1/Portfolio-Website.git
cd Portfolio-Website

# Install dependencies
npm install

# Create environment file
cp .env.example .env
# Edit .env with your values

# Start the development server
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Environment Variables

Create a `.env` file based on `.env.example`:

```env
PORT=3000
EMAIL_SERVICE=hotmail
EMAIL_USER=your_email@outlook.com
EMAIL_PASS=your_password
EMAIL_RECEIVER=your_email@outlook.com
```
